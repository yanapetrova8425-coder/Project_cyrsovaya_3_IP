# Салон красоты Neonka — Курсовой проект

## Описание
Клиент-серверное веб-приложение для салона красоты «Neonka» (г. Шумерля).
Позволяет клиентам записываться на услуги онлайн, оставлять отзывы,
регистрироваться и входить в личный кабинет.

## Технологии
- **Клиентская часть:** HTML5, CSS3 (Grid/Flexbox), JavaScript (чистый, без jQuery)
- **Серверная часть:** PHP 8, PDO, MySQL
- **AJAX:** асинхронная отправка данных через fetch + FormData

## Установка и запуск

### 1. Установите XAMPP
- Скачайте: https://www.apachefriends.org/
- Установите и запустите
- В панели управления XAMPP нажмите **Start** у **Apache** и **MySQL**

### 2. Скопируйте проект
- Скопируйте папку `Курсовая` в `C:\xampp\htdocs\`
- Переименуйте в `neonka` (чтобы путь был `C:\xampp\htdocs\neonka`)

### 3. Создайте базу данных
- Откройте **phpMyAdmin** (http://localhost/phpmyadmin)
- Нажмите вкладку **«Импорт»**
- Выберите файл `database/neonka_db.sql`
- Нажмите **«Вперёд»**

### 4. Настройте подключение к БД
Откройте файлы в папке `php/` и проверьте параметры подключения:
```php
$host = '127.0.0.1';
$db = 'neonka_db';
$user = 'root';
$pass_db = '';  // в XAMPP по умолчанию пустой пароль
```

### 5. Откройте проект в браузере
- Введите: **http://localhost/neonka**

## Функционал

### Клиентская часть
- **Главная страница** — герой-блок, преимущества, услуги, акции, команда, комплексы, контакты
- **Каталог услуг** — слайдер работ, карточки услуг, подробный прайс-лист
- **Онлайн-запись** — форма с валидацией (9 типов полей ввода)
- **Галерея** — слайдер «До и После», сетка фотографий, шаги визита
- **Отзывы** — просмотр отзывов, форма добавления нового
- **Личный кабинет** — вход и регистрация через модальные окна

### Серверная часть
- **Регистрация** — валидация, хеширование пароля (password_hash), проверка уникальности email
- **Вход** — проверка email/пароля через password_verify
- **Запись на приём** — валидация даты/времени, сохранение в БД
- **Отзывы** — валидация рейтинга и текста, сохранение в БД

## База данных (3 таблицы)
| Таблица | Поля |
|---|---|
| **users** | id, name, phone, email, password, created_at |
| **bookings** | id, client_name, client_phone, client_email, service, master, booking_date, booking_time, comment, created_at |
| **reviews** | id, client_name, rating, review_text, created_at |
